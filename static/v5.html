05 / EVIDENCE, NOT MARKETING

What the experiment proves — and doesn't

Run matched Monte Carlo episodes using synthetic canonical work-order templates. Every episode uses the same orders, durations and disturbances for both staging dispatch policies. These are not airline savings.

No benchmark yet. Run the experiment after releasing some work orders.

Evidence boundary

What works: historical synthetic schema, as-of replay, real numerical optimizers, operational controls, shared-event queue tests, approval state, client projections.

What remains unverified: 3D ULD restraint/contour, actual Cathay shipment/inventory feeds, calibrated inspection probabilities, workforce reality, booking authorization, real cost savings.

When in doubt: choose explicit hold, unknown or escalation — never a fictional certified instruction.
