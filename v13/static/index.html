    Which box goes first?

    Imagine you’re helping at an airport. Planes leave on a schedule, boxes keep arriving, and only a few crews are free. RELAY helps you decide which boxes to load next.

    1. Can it go?

      Check the box’s booking, papers, and special handling rules. The plane needs room and the crew needs enough time before loading closes.

    2. Which box needs help first?

      A box might move up the list because its plane is about to close, it needs to stay cold, or it has a promise to fly first.

    3. Which jobs fit together?

      Look at a short list and pick a group of jobs that uses the crews well. If there’s only one specialist, only one specialist job can start now.

    Try it with three boxes

    How does the math paper fit in?

    Picture a row of squares. A move uses two neighboring squares, so moves that share a square can’t both happen. You can work along the row and keep track of the best set of moves so far.

    The v13 research uses this idea to study some cargo swaps that clash with their neighbors. It connects those swaps to the tile-pairing puzzles in Musiker and Schiffler’s Cluster expansion formulas and perfect matchings. The live assisted dispatcher uses a different method. It compares groups drawn from up to nine jobs for the crews available now.
